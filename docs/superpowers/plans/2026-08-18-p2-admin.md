# P2 后台实施计划（FastAPI + Setup + 双登录 + 八栏目）

> **For agentic workers:** 本计划在单一会话内联执行。步骤用 `- [ ]` 追踪。

**Goal:** 交付可用的管理后台：首启 Setup 三步向导、本地 + Li&Pass OIDC 双登录、八栏目全站内容管理、Hugo 预览与分段重建，全部经本地运行验证。

**Architecture:** FastAPI + SQLite + Jinja2；内容仍是文件（Markdown/YAML）单一事实来源；保存/预览调用 `scripts/build.py`；OIDC 用 authlib（发现文档 + PKCE + id_token 校验 + 回程登出）。

**Tech Stack:** FastAPI、uvicorn、Jinja2、PyYAML、python-multipart、httpx、authlib；密码哈希用 stdlib `hashlib.pbkdf2_hmac`（SHA-256，600k 迭代；零原生依赖，替代 Argon2/scrypt——macOS 自带 Python 无 scrypt，容器与本地需同一实现，理由记录于本文档与 AGENTS）。

## Global Constraints

- 公开站零交互：后台全部挂在秘密路径 `ADMIN_PATH`（默认 `admin`）下，前台无任何入口
- 单管理员：`admin_account` 唯一一行；OIDC 登录仅当 `sub == oidc_sub` 放行；不自动建号
- 安全：HttpOnly 会话 Cookie、CSRF 校验、登录限速、可选 IP 白名单、密码 scrypt、OIDC secret 只走环境变量
- 渲染单一出处：预览与线上都走 Hugo（`scripts/build.py --preview` / `--full`），后台不引入 Markdown 渲染器
- 全站可见内容后台可改：八栏目（品牌/页面文案/首页设置/文章/项目/时间线/关于我/资源）
- 内存：admin 进程单 worker；构建经 `GOMEMLIMIT=256MiB`
- 备案：页面不出现假备案号；后台登录页无对外入口
