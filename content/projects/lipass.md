Li&Pass 是 Li& 系列的统一身份提供商：后端 FastAPI + PostgreSQL + Redis，前端 React + TypeScript，通过标准 OIDC/OAuth2 协议向授权网站提供登录能力。

本项目是学习 OIDC、PKCE、联邦登出与审计的完整实践。
